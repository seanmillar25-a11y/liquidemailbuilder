Team lists & settings

    

      

        
Courses

        
One course per line, using the real Gecko dropdown values. You can paste Gecko's option export as it is (Value|Label|hidden): courses marked hidden stay in the matching rules but aren't offered when choosing courses. The tool picks single-word keywords that no other course shares (this gets round Gecko's hidden-character bug) and checks sub-variants first. To set keywords yourself: Law => law.

        
      

      

        
Keyword check

        
The order is the order Liquid checks them in. Every row should show ✓.

        

      

      

        
      

      

        
Domicile regions

        
One region per line: Region name: keyword, keyword. Use single words only. Anyone who matches none of these counts as International.

        
      

      

        
Saved links

        
Approved links the team can pick from (button links, image links, and "Saved link" in the text toolbar). One per line: Name | URL.

        
      

      

        
Saved snippets

        
Standard wording to insert from the text toolbar, e.g. contact lines. One per line: Name | text. Use \n for a line break.

        
      

      

        
Link tracking (UTM)

        
When tracking is turned on for an email, links to these domains get utm_source, utm_medium, utm_campaign (from the email's campaign name) and utm_content (from the block name). Links that already have UTM tags are left alone.

Import from a content matrix

    

      
Choose a matrix file (.xlsx), then the sheet for the email you're building. Each row becomes a course or domicile variation. Each column becomes a block, or part of a button. The matrix shorthand ({?url?}, {?b?}, *link to:*, (mailto:…)) is converted for you.

Edit an existing Liquid template

    

      
Open the email template in Gecko, copy all of its HTML and paste it below. Emails made in this builder re-open exactly. For older templates, the builder reads the course and domicile logic and rebuilds the blocks. Anything it can't convert is kept as Custom HTML.
